## 🆘 **SOLUCIÓN DE PROBLEMAS:**

### **Error: "Failed to fetch"**
```
Causa: Netlify Function no configurada
Solución:
1. Verifica variable ANTHROPIC_API_KEY
2. Redeploy
3. Hard refresh (Ctrl+Shift+R)
```

### **Error: "API key invalid"**
```
Causa: API key incorrecta
Solución:
1. Verifica que copiaste bien la key
2. No debe tener espacios
3. Empieza con "sk-ant-api03-"
```

### **Botón "🤖 + IA" no aparece**
```
Causa: Tema no al 100%
Solución:
1. Verifica progreso del tema
2. Debe ser exactamente 100%
3. Recarga la página
```

### **Generación muy lenta (>30 seg)**
```
Causa: API lenta o sobrecargada
Solución:
1. Espera pacientemente
2. No cierres la ventana
3. Primera vez suele ser más lenta
```
